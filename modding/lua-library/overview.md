**[inferred]** `main_globals` contains static candidates from column-zero
assignments and function declarations. It records the root of a dotted name,
filters locally declared names and `self`, and masks comments/strings. It is
not a Lua interpreter or a complete scope analysis: computed assignments,
indented definitions and aliases may be missed, and a name may be filtered
because it is local elsewhere in the file. Empty cells do not mean the file has
no side effects. `one_line_role` is an original, inferred label from the folder
and filename; it is not a copied comment or a verified behavioral summary.

## Global tables and helper families [observed]

The index records `ZomboidGlobals` in `shared/defines.lua`, `SandboxVars` in
`shared/Sandbox/SandboxVars.lua`, `ISBaseTimedAction` in its shared action file
and `ISTimedActionQueue` in the client queue file. Loot-related roots include
`SuburbsDistributions`, `ProceduralDistributions` and `VehicleDistributions`.
The basename `Distributions.lua` does not imply that its root table is named
`Distributions`; inspect the indexed identifiers and registration code.

**[inferred]** Use the index to find the owning module, then read the relevant
function in the installed file. Cross-check Java-facing names against
[how-binding-works.md](../lua-api/how-binding-works.md) and the exposed-methods
catalogue. Lua table names, Java class aliases and files are related naming
systems, not a universal one-to-one mapping.
