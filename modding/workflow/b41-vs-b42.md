# Legacy samples and the installed B42 format

Survey date: 2026-10-24. Build: jar sha256 prefix `e1a69eb7`.
Sources: installed sample folders and current media files, with loader/layout
corroboration from the read-only engine source. Claims are **[observed]** unless
tagged **[inferred]** or **[unknown]**. No B41 installation was available for a
direct version-to-version comparison.

## What the files establish

**[observed]** Both supplied mod samples are flat: their `mod.info` and `media`
sit immediately beneath the sample mod folder. `examplemod` has Lua files outside
the modern client/server/shared split. The current vanilla Lua tree has those
three sides, and loader discovery checks `common` and a selected version directory.
The current discovery loop also explicitly excludes the folder named `examplemod`.
See [mod-layout.md](mod-layout.md) for a versioned hello-world layout.

**[observed]** `media/luaexamples/testtimed.lua` requires `timedactionshelper`;
there is no matching module in the current three-side vanilla Lua inventory.
Current actions instead derive from `ISBaseTimedAction`, and many separate
`perform`, `complete`, duration and server-specific hooks. See
[timed-actions.md](../lua-library/timed-actions.md).
**[inferred]** Treat old action demonstrations as historical illustrations,
rather than copying their API calls into a current mod.

**[observed]** The current item data uses namespaced `ItemType` and item tags;
no direct `Type` or `DisplayName` occurs in the surveyed item definitions.
Module-level crafting uses `craftRecipe`; no lowercase legacy `recipe` blocks
occur in the current script tree. Entity `component CraftRecipe` is another
distinct context. English item labels are in `ItemName.json` under full item IDs.
The complete translation inventory is mostly JSON rather than old-style Lua-like
translation text. See [items.md](../scripts/items.md),
[crafting.md](../scripts/crafting.md) and [translations.md](translations.md).

**[inferred]** For a migration, first establish the current versioned layout,
move Lua into the intended side, then check each changed API/grammar against the
installed files and parser catalogue. Check action completion/network behavior
separately from UI presentation. Test new item/recipe identifiers rather than
assuming a legacy definition loads because its text looks familiar.

## Comparison limits

**[unknown]** The installed legacy samples do not identify their original game
build, and this survey cannot attribute every difference specifically to the
B41→B42 boundary. It does not provide a complete migration matrix, date the JSON
transition or prove that every old key/API has been removed. An absent vanilla
usage and an unsupported parser key are different findings. The file inventory
in [mod-sample-files.csv](../data/mod-sample-files.csv) identifies the sample files
without copying game content.

**[observed]** The comparison concerns installed legacy samples and current file formats.
**[unknown]** In-game legacy-mod and migration behaviour remains unverified.
